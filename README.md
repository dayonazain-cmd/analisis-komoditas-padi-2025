# Analisis Komoditas Padi Indonesia Tahun 2025

## Tentang Proyek
Repositori ini berisi proyek analisis data yang berfokus pada evaluasi Luas Panen, Produktivitas, dan Produksi Padi di 38 Provinsi di Indonesia pada tahun 2025. 

Analisis ini mencakup tahapan Data Understanding, Data Cleaning (penanganan nilai kosong, duplikat, dan deteksi outlier ekstrem), eksplorasi data (EDA), hingga pemodelan prediktif menggunakan algoritma Machine Learning (Regresi Linear).

## Struktur Repositori
- `analisis_produksi_padi_2025.ipynb` : File Jupyter Notebook utama yang berisi seluruh kode Python, narasi analisis, dan visualisasi data.
- `Luas Panen, Produktivitas, dan Produksi Padi Menurut Provinsi, 2025.csv` : Dataset mentah yang digunakan dalam penelitian ini.

## Library Python yang Digunakan
- `pandas` dan `numpy` : Untuk manipulasi dan pembersihan data.
- `matplotlib` dan `seaborn` : Untuk membuat visualisasi data (grafik, boxplot, heatmap).
- `scikit-learn` : Untuk pemodelan regresi dan evaluasi akurasi model.

## Cara Menjalankan Proyek
1. Unduh file `.ipynb` dan `.csv` dari repositori ini.
2. Buka file `.ipynb` menggunakan Google Colab atau Jupyter Notebook lokal.
3. Pastikan file `.csv` berada di direktori (folder) yang sama dengan file `.ipynb`.
4. Klik menu Runtime > Restart and Run All untuk menjalankan seluruh kode dari awal.
